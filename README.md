# Instagram Web Clone

A responsive, pixel-perfect clone of **Instagram Web** built to mirror Meta's modern Comet design system, typography, colors, animations, and interactive behaviors.

## Features Included

- **Stories Bar**:
  - Signature gradient story rings (`#f09433` -> `#bc1888`).
  - Interactive **Fullscreen Story Viewer** with animated 5-second progress bars, auto-advance, and keyboard/touch navigation.
- **Main Feed**:
  - High-resolution feed cards with verified badges, timestamps, locations.
  - **Double-tap to like** with animated pop-up heart!
  - Real-time like button, save/bookmark toggle, and link sharing.
  - Interactive **Comments Section**: Type and submit real-time comments directly under any post.
- **Sidebars & Responsive Layout**:
  - Full desktop left sidebar (Home, Search, Explore, Reels, Messages, Notifications, Create, Profile, Appearance/Theme toggle).
  - Compact icon-only sidebar for medium screens / tablets.
  - Mobile bottom navigation bar and mobile top header for phones (`<768px`).
  - Right sidebar with current profile switch, "Suggested for you" cards with working Follow/Unfollow toggles, and official footer.
- **Create Post Workflow**:
  - Drag-and-drop or select an image file from your computer.
  - Add caption and location.
  - Click Share: immediately prepends the post to the live feed and increments your profile post count!
- **Explore & Reels Tabs**:
  - 3x3 Explore photo & video grid with hover statistics.
  - Vertical Reels video feed with likes, audio tags, and comment overlays.
- **Direct Messages (DMs)**:
  - Interactive chat sidebar with sample message threads and active conversation area.
- **Dark & Light Mode**:
  - Seamless toggle between Instagram's AMOLED dark theme and light theme, with preference saved in localStorage.

## How to Run

Simply double-click [`start.bat`](start.bat) or open [`index.html`](index.html) in any browser (Chrome, Edge, Safari, Firefox).
